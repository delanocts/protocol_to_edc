Protocol → USDM

Clinical protocol PDF to a CDISC USDM v4 study definition.

1 Study

Create a study or upload a protocol

ASCII letters, digits, dot, underscore and hyphen only. A non-breaking hyphen pasted from a document will be rejected here rather than failing later.

Text-layer PDFs only — scanned documents need OCR, which is out of scope.

2 Configure

Domain agents

Turn off any domain whose data you do not need. A disabled agent makes no API call and costs nothing. Required USDM content it would have produced is reported in the gap report, or stubbed in stub mode.

3 Run

4 Results

Runs locally. The only outbound call is to the Anthropic API, using the key in your .env. Equivalent command line: python run_build.py <STUDY>
